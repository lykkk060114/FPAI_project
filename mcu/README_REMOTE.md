# 坦克蓝牙串口遥控器

`pc_remote_controller.py` 是一个 Windows/Linux/macOS 都能运行的 Tkinter 图形界面。电脑通过 USB 转 TTL 模块连接蓝牙串口模块，使用 9600 baud、8 数据位、无校验、1 停止位（9600 8N1）。

在 Windows 上也可以直接双击目录里的 `TankRemote.exe`，不需要安装 Python。

## 运行

```text
python -m pip install -r requirements.txt
python pc_remote_controller.py
```

上面是两条命令，需要分开执行；不要把它们连成一条命令。

连接后选择蓝牙模块对应的 COM 口，点击“连接”。W 或上箭头前进，S 或下箭头后退，A/左箭头左转，D/右箭头右转。按住一个前后键和一个左右键可以斜向行驶：AW 左前、WD 右前、AS 左后、SD 右后。若按住 AW 时再按 D，命令会切换为 WD；松开 D 后会恢复为仍按住的方向。释放按键、Space 或 Escape 会发送停车命令。

## 蓝牙串口命令

电脑端发送单字节 ASCII 命令，并以 50 ms 周期重发当前按键。界面上的斜向名称对应右侧的协议字节：

| 字节 | 动作 |
| --- | --- |
| `W` | 前进 |
| `S` | 后退 |
| `A` | 左转 |
| `D` | 右转 |
| `Q` | AW，左前 |
| `E` | WD，右前 |
| `Z` | AS，左后 |
| `C` | SD，右后 |
| `X` | 停止 |

这个目录中的底盘固件文件没有被修改。电脑端只负责通过选定的 COM 口发送上述字节；蓝牙接收端或底盘控制程序需要按同样的命令表解析它们。建议接收端实现超时停车，例如 200 ms 没有新命令时停止电机。
